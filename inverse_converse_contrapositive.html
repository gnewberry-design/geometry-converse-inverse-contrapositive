🔄 Converse, Inverse & Contrapositive

Flip it! Negate it! Understand the logic! 🧠✨

🎯 Mastery goal: 80% or higher

🎯 Learning Targets

I can identify the hypothesis and conclusion of an if–then statement. I can write its converse, inverse, and contrapositive. I can identify which forms are logically equivalent and explain my thinking.

Success criteria: I can correctly answer at least 8 of 10 exit-ticket questions.

🌎 Why Are We Learning This?

Logic helps us check claims, write mathematical proofs, troubleshoot technology, and spot mistakes in everyday reasoning. Changing the order of an if–then statement—or adding “not”—can completely change its meaning!

💻 “If I enter the correct password, then I can access my account.” Does being able to access my account prove that I entered the password? Not necessarily—there might be another sign-in method.

👩‍🏫 I DO — Learn the Four Forms

A conditional statement has a hypothesis (p) and a conclusion (q): If p, then q.

🟣 Original

p → q

If p, then q.

Keep the order.

🔵 Converse

q → p

If q, then p.

🔁 Switch the parts.

🟢 Inverse

¬p → ¬q

If not p, then not q.

🚫 Negate both parts.

🩷 Contrapositive

¬q → ¬p

If not q, then not p.

🔁🚫 Switch AND negate.

📐 Geometry Example

Original: If an angle measures 90°, then it is a right angle.
Converse: If an angle is a right angle, then it measures 90°.
Inverse: If an angle does not measure 90°, then it is not a right angle.
Contrapositive: If an angle is not a right angle, then it does not measure 90°.

🧠 Important Logical Equivalences

✅ The original and contrapositive always have the same truth value.
✅ The converse and inverse always have the same truth value.
⚠️ The converse does not necessarily have the same truth value as the original.

💡 Memory trick: Converse = Change order | Inverse = Insert NOT | Contrapositive = Change order + Insert NOT.

🔍 Watch Out!

Original: “If a figure is a square, then it is a rectangle” is true. Converse: “If a figure is a rectangle, then it is a square” is false. A rectangle can have unequal adjacent side lengths.

🎓 Review & Reteach

🔁 I mixed up converse and inverse.

Converse: reverse the two parts. Inverse: keep their positions but negate both. Practice writing p and q first.

🚫 I forgot how to write a negation.

To negate “the angle is acute,” write “the angle is not acute.” Do not automatically replace it with “obtuse,” because right angles also exist.

🧩 I missed the equivalent-statements questions.

Original ↔ contrapositive; converse ↔ inverse. Each pair always shares a truth value.
